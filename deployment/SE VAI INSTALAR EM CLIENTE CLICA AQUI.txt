============================================================
SE ESTA E A MAQUINA CLIENTE, LEIA E EXECUTE
============================================================

1. Confirme que o ADMIN ja foi instalado e esta ligado.
2. Se voce baixou o pacote publicado, abra a pasta artifacts\release\CLIENTE.
   Se voce baixou o codigo do GitHub, abra a pasta deployment do repositorio.
3. Nao copie somente o .bat. No codigo do GitHub, ele baixa e valida o pacote
   CLIENTE automaticamente; se nao houver internet, sera necessario gerar o
   release com o .NET 8 SDK ou usar o pacote publicado completo.
4. Execute o arquivo INSTALAR_CLIENTE.bat.
5. Autorize a janela do Windows quando aparecer.
6. O instalador copia o pacote CLIENTE para C:\Program Files\Adrenalina\.
7. Ele cria atalho na area de trabalho e inicializacao automatica.
8. Abra o Adrenalina.Launcher.exe pelo atalho.
9. Escolha CLIENTE.
10. Informe a URL do ADMIN, se solicitado.
11. Copie exatamente a URL mostrada no ADMIN. Na instalacao padrao ela comeca com
    https://. Nao use localhost ou 127.0.0.1 no computador CLIENTE.
12. Se o teste de conexao avisar sobre certificado, copie o arquivo .cer da pasta
    C:\ProgramData\Adrenalina\certs do ADMIN para esta maquina. No Client, clique
    em INSTALAR CERTIFICADO DO ADMIN e selecione esse arquivo. Depois teste de novo.
13. Use PAREAR CONFIGURACAO e informe os 6 numeros mostrados no ADMIN.
14. Aguarde o administrador aprovar a estacao. O Client verifica automaticamente;
    nao e necessario clicar em PAREAR uma segunda vez.
15. Depois da aprovacao, o proprio Client inicia a instalacao do Agent.
16. Autorize a janela UAC do Windows quando aparecer.
17. Nao feche o Client enquanto o pareamento e a instalacao terminam.

Se aparecer "Falha na instalacao", leia o log mostrado pelo proprio .bat ou
abra:

C:\ProgramData\Adrenalina\logs\Install-CLIENTE.latest.log

Depois disso, o Client e o Agent iniciarao automaticamente com o Windows.

Arquivos principais depois da instalacao:

C:\Program Files\Adrenalina\Adrenalina.Launcher.exe
C:\Program Files\Adrenalina\Adrenalina.Client.exe
C:\Program Files\Adrenalina\Adrenalina.Agent.exe

O pacote CLIENTE nao contem Adrenalina.Admin.exe. O Agent e um servico, nao
abra o executavel dele com duplo clique.
